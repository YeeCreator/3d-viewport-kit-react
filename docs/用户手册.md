# manual-viewport-3d-kit-react-用户手册-20260311-001

## 1. 文档目的

本文档面向工具包使用者，说明如何在 React 项目中接入 `viewport-3d-kit-react`，并正确使用主视口、变换工具和小地图。

## 2. 功能概览

当前工具包提供以下能力：

- 主视口组件 `Viewport3D`
- 小地图组件 `MiniMap3D`（可选）
- 右键菜单与工具栏 UI（可选）
- 基础对象选择与高亮
- 变换模式切换：平移、旋转、缩放
- 受控/非受控状态管理（小地图、选中对象、变换模式、对象变换）

## 3. 安装依赖

在宿主项目安装：

```bash
npm install viewport-3d-kit-react three @react-three/fiber @react-three/drei react react-dom
```

## 4. 快速接入

```tsx
import { useMemo, useState } from 'react';
import { Viewport3D } from 'viewport-3d-kit-react/react';
import { createDemoEntities } from 'viewport-3d-kit-react/core';

export function Demo() {
  const entities = useMemo(() => createDemoEntities(), []);
  const [miniMapEnabled, setMiniMapEnabled] = useState(false);

  return (
    <div style={{ width: '100%', height: '70vh' }}>
      <label>
        <input
          type="checkbox"
          checked={miniMapEnabled}
          onChange={(event) => setMiniMapEnabled(event.currentTarget.checked)}
        />
        显示小地图
      </label>

      <Viewport3D
        entities={entities}
        miniMapEnabled={miniMapEnabled}
        onMiniMapEnabledChange={setMiniMapEnabled}
        miniMapMode="top-down"
        className="app-viewport"
      />
    </div>
  );
}
```

## 5. 样式引入

如果你在当前仓库内联调（例如运行 `npm run dev`）并使用内置 UI（工具栏和右键菜单），可直接引入：

```tsx
import 'viewport-3d-kit-react/src/styles/viewport.css';
import 'viewport-3d-kit-react/src/styles/radix-ui.css';
```

说明：

- `viewport.css` 定义了主视口容器、小地图定位和覆盖层布局。
- `radix-ui.css` 定义了工具栏和右键菜单样式。
- 发布到 npm 供外部项目消费时，建议在打包阶段显式导出样式入口，或将样式复制到宿主项目统一管理。
- 你也可以只保留结构类名并覆盖为业务样式。

## 6. 交互说明

在默认实现中：

- 左键单击对象：选中对象并高亮。
- 点击空白区域：清空选中。
- 工具栏按钮：切换平移、旋转、缩放模式。
- 拖拽 `TransformControls`：实时更新对象变换。
- 右键菜单：可切换模式、小地图开关、取消选中。

## 7. 关键属性

`Viewport3D` 常用属性：

- `entities?: ViewportEntity[]`：场景对象数组。
- `miniMapEnabled?: boolean`：受控小地图开关。
- `defaultMiniMapEnabled?: boolean`：非受控默认小地图状态。
- `miniMapMode?: 'top-down' | 'follow'`：小地图模式。
- `selectedEntityId?: string | null`：受控选中对象。
- `defaultSelectedEntityId?: string | null`：非受控默认选中对象。
- `transformMode?: 'translate' | 'rotate' | 'scale'`：受控变换模式。
- `defaultTransformMode?: 'translate' | 'rotate' | 'scale'`：非受控默认变换模式。
- `entityTransforms?: EntityTransformMap`：受控对象变换字典。
- `defaultEntityTransforms?: EntityTransformMap`：非受控默认变换字典。
- `onMiniMapEnabledChange`、`onSelectedEntityIdChange`、`onTransformModeChange`、`onEntityTransformsChange`：状态变化回调。

## 8. 受控与非受控使用建议

推荐在业务系统中优先使用受控模式：

- 便于将状态同步到上层状态管理。
- 便于做撤销/重做、权限控制、日志审计。

当你希望快速原型验证时，可采用非受控模式：

- 仅传入 `default*` 属性，内部自动维护状态。

## 9. 数据模型说明

`ViewportEntity` 基本结构：

```ts
interface ViewportEntity {
  id: string;
  name: string;
  position: [number, number, number];
  size: [number, number, number];
  rotation?: [number, number, number];
  color: string;
}
```

`EntityTransformMap` 基本结构：

```ts
type EntityTransformMap = Record<
  string,
  {
    position: [number, number, number];
    rotation: [number, number, number];
    scale: [number, number, number];
  }
>;
```

## 10. 常见问题

### 10.1 小地图不显示

检查项：

- `miniMapEnabled` 是否为 `true`。
- 容器是否有足够高度（建议 `height >= 360px`）。
- 样式是否覆盖了 `.vk-minimap` 的定位或尺寸。

### 10.2 变换后外部状态未更新

检查项：

- 是否传入了 `entityTransforms` 但未实现 `onEntityTransformsChange`。
- 外部回调是否正确写回最新变换字典。

### 10.3 对象无法被选中

检查项：

- 对象 `id` 是否唯一。
- 是否有外层事件阻止了 Canvas 指针事件。
